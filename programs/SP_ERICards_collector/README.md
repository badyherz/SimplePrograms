## Simple Programs: ERICards Collector powered by Python

This README is just for additional information about the program.
There are some nice features for a better user experience, but some are missing or need a bit of manual work.
The program folder can be found in your local Documents folder in the Simple Programs folder.

**Adding a database & reference text:**
Database:
You can create your own database in a selected language with the "ERICards Database Compiler", this only works if https://www.ericards.net/ has not changed their layout. (Last tested: 10/2026)
Else I provided some database that I compiled and tested, these can be found [here](https://github.com/badyherz/SimplePrograms/tree/main/programs/SP_ERICards_collector/database_and_refernce_text).
Just download your database and follow the instructions in the program.
Note: It is not guaranteed that the compiler will work with every language, I only tested English, German, Spanish and French.

Reference Text:
This refers to the Glossary and H & P Statements. The program comes with English only. You can edit the file in the program folder and add your translation manually.
Else I provided a reference text file that includes the following languages: English, German, Spanish, French. This can be found [here](https://github.com/badyherz/SimplePrograms/tree/main/programs/SP_ERICards_collector/database_and_refernce_text).
Just replace the file in the program folder and in the program under settings click on "Reload Glossary Texts.

**Adding icons:**
This has to be done manually, but I provided icons. You just have to download them and place them in the icon folder of the program.
In the program under settings you can find an open icon folder option.
If you wish you can create your own, just name them like I did.
Else when there are none the program uses standard color templates.

You can find the icons [here](https://github.com/badyherz/SimplePrograms/tree/main/programs/SP_ERICards_collector/icons).
