## About

All of them are created with the help of chatGPT and other tools/internet help, and all are written in Python because I'm not great at coding at all. (And I kinda enjoy Python.)

They are really simple and lack design and cohesion, but they work, and that's the point.

I only make them when I need them, and I will add more when I create more. I'm sharing them here because maybe someone finds them as helpful as I do.

## Getting Started

I build them for Windows with PyInstaller. (Maybe in the future for Linux too.)

1. Go to the newest [release](https://github.com/badyherz/SimplePrograms/releases).

3. Or build it yourself!

### Bulk File-Extension Changer

Renames the file extension of one or multiple files. This does **not** convert them! But if you know what you're doing, this can be handy. I used it in multiple ways, like changing .webp to .jpg.

### Bulk File-Name Changer

Changes or deletes specific parts of the file name of one or multiple files.

### Bulk File-Renamer for TV Series

Created for renaming TV series for home media use, because who wants to rename 30 files or so? Can be useful for general renaming too.

### EXE File Search

Lets you search for .EXE files in folders and sort them. Created because I wanted to find a specific old hidden program. Has a simple cache system to remember searches.

### GIF to PNG Converter

Extracts all the frames of a .GIF and saves them in a folder as .PNG files. Used for creating manual gifs. Can also create simple gifs from frames.

### Grade Calculator

Used to see a simple overview with graphs of the results of exams. Needs manual input for each exam.

### Metadata Remover

Simple program to delete almost all metadata from images and videos (needs FFmpeg for videos). I used it for uploading simple images onto the internet.

### Simple Expense Manager

Tracks, at the moment, electricity and grocery expenses with all the necessary statistics and even charts.

- Settings for different currencies and language file support
- Data import/export and a simple backup system if something goes wrong
- More information on setup [here](https://github.com/badyherz/SimplePrograms/tree/main/programs/SP_simple_expense_manager)!

### Simulated Button Pressing

Simulates key presses for the mouse and keyboard with custom activation key and hold and toggle option. Intended for gaming.

### Text Comparison

Compares two strings of text and highlights the difference. I used it to compare hash codes, but it can also be used for bigger texts.

### Text Encoder and Decoder

Encodes and decodes text/strings with different methods (a few, may get more in the future). Used it for hidden messages in games and hidden web links.

### TV Series Tracker

Lets you track TV series.

- Add and remove episodes
- Progress bar
- Archive to clean up a bit
- Import and export functions to save your data
- Automatically saves when you close the program
